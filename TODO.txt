Associer plusieurs départements à un même utilisateur
 - Tous les utilisateurs, peu importe leur rôle, devraient pouvoir être associés à plusieurs départements.
 - Les utilisateurs devraient pouvoir basculer d'un département à l'autre dans la section d'accueil
 - Le super admin peut associer un utilisateur à plusieurs départements
 - Les coordonnateurs ne peuvent associer un utilisateur qu'au département actif (celui sélectionné dans l'accueil)
 - Il faudrait réutiliser les comptes utilisateurs: si un coordonnateur essaie d'ajouter un utilisateur existant dans son département, il faut ajouter un département à l'utilisateur sans en créer un nouveau
 - Les rôles de coordonnateur et d'enseignant peuvent différer d'un département à l'autre pour un même utilisateur. Par exemple, le coordonnateur du département d'informatique pourrait être un simple enseignant dans le département de technique administrative.
 - Le super admin a tous les privilèges et est nécessairement coordonnateur de tous les départements auquel il est associé.
 const token = "VOTRE_TOKEN_ICI";

fetch('/api/admin/migrate-multi-dept', {
    method: 'POST',
    headers: {
        'Authorization': `Bearer ${token}`
    }
})
.then(response => response.json())
.then(data => {
    if (data.success) {
        console.log(`✅ Migration réussie ! ${data.migratedCount} profils ont été mis à jour.`);
    } else {
        console.error('❌ Erreur lors de la migration :', data.error);
    }
})
.catch(error => console.error('Erreur réseau :', error));
